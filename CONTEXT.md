# MindForge Learning

MindForge helps one learner turn private source material into an ongoing learning conversation, durable study notes, and evidence-based practice.

## Language

**Study Session**:
A learner-owned workspace containing source material, professor dialogue, study artifacts, and practice history for one learning topic.
_Avoid_: Chat, thread, project

**Study Artifact**:
A durable generated learning note, such as a summary, concept set, or multilingual explanation, that can be reopened, discussed, or exported.
_Avoid_: Tool result, output, generated file

**Practice Round**:
An ordered, resumable set of questions generated from one study session and completed as one learning attempt.
_Avoid_: Quiz result, test document

**Practice Question**:
One question within a practice round, with its answer criteria and teaching explanation.
_Avoid_: Prompt, card

**Practice Response**:
A learner's submitted answer and its evaluation for one practice question.
_Avoid_: Message, submission

**Mastery Signal**:
Evidence inferred from practice responses about concepts the learner understands or should review; it is not a permanent judgment of ability.
_Avoid_: Grade, intelligence score
